#淘宝用户行为分析与用户分层



## 1. 项目背景

基于 2017 年 11 月 25 日至 12 月 3 日的淘宝用户行为日志（共 104 万行记录），完成数据清洗、转化漏斗分析、DAU 监测、复购洞察及 RFM 用户分层。



## 2. 技术栈

- Python (Pandas, NumPy, Matplotlib, Seaborn)

- 数据格式：Parquet / CSV



## 3. 核心分析结论

| 指标 | 结果 |

| 总用户数 | 10,202 人（其中浏览用户 10,169 人） |

| 同商品支付转化率（浏览→收藏/加购→支付） | 9.23%（939/10,169；严格同商品链路） |

| DAU 峰值 | 12 月 2 日（10,019 人） |

| 热销类目 Top 1 | 类目 2735466（支付 385 次） |

| 热销单品 Top 1 | 商品 812879（浏览 298 次） |

| 新用户 7 日复购率 | 54.37%（3,806/7,000，不含首购当天；受数据采样偏差影响） |

| RFM 高价值用户 | 3,096 人（购买用户中占 44.23%） |



## 4.文件结构说明

- `notebooks/`：按顺序存放 5 个分析步骤的完整代码。

- `images/`：存放所有可视化图表。

- `date/`：原始 CSV 和清洗后的 Parquet 数据，可直接加载使用。(原文件过大没有载入,只加入了清洗过后的parquest版本)



## 5. 数据局限

本数据集为定向采样（优先抽取核心活跃期的高活用户），且部分购买缺少同一商品的前置浏览、收藏或加购记录，因此严格同商品漏斗结果为保守口径。分析结论仅适用于高活用户群体，不代表全量用户表现。

全量购买用户为 7,000 人；此前用户级顺序漏斗购买用户为 6,882 人，相差 118 人，其中 27 人没有浏览记录，91 人首次购买早于首次浏览。最终严格同商品漏斗购买用户为 939 人。7 日复购分析中，未在首购后第 1 至 7 天内跨日复购的购买用户为 3,194 人。
