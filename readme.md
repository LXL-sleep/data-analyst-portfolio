# 淘宝用户行为分析与用户分层



## 1. 项目背景

基于 2017 年 11 月 25 日至 12 月 3 日的淘宝用户行为日志（共 104 万行记录），完成数据清洗、转化漏斗分析、DAU 监测、复购洞察及 RFM 用户分层。

## 数据来源

本项目使用的数据集为 **阿里天池“UserBehavior”淘宝用户行为数据集**。
- **数据来源**：阿里天池大赛平台
- **数据集链接**：https://tianchi.aliyun.com/dataset/649
- **数据说明**：该数据集包含了 2017 年 11 月 25 日至 12 月 3 日期间，约 100 万随机用户的行为日志（约 1 亿条记录），涵盖 `pv`（浏览）、`buy`（购买）、`cart`（加购）、`fav`（收藏）四种行为类型。
- **使用版本**：本仓库使用的是经过随机抽样的精简版（104 万行），仅用于本地分析与作品集展示。
- **文件说明**：因原始数据文件较大，已通过 `.gitignore` 排除。清洗后的 `Parquet` 格式数据已上传至本仓库的 `data/` 目录，可直接加载使用。

> 如需复现完整分析，请自行从天池平台下载原始数据集。

## 2. 技术栈

- Python (Pandas, NumPy, Matplotlib, Seaborn)

- 数据格式：Parquet / CSV



## 3. 核心分析结论

| 指标 | 结果 |

| 总用户数 | 10,169 人 |

| 支付转化率（浏览→支付） | 68.8% |

| DAU 峰值 | 12 月 2 日（10,019 人） |

| 热销类目 Top 1 | 类目 2735466（支付 385 次） |

| 热销单品 Top 1 | 商品 812879（浏览 298 次） |

| 新用户 7 日复购率 | 65.47%（受数据采样偏差影响） |

| RFM 高价值用户 | 6,066 人（占 59.5%） |



## 4. 文件结构说明

- `notebooks/`：按顺序存放 5 个分析步骤的完整代码。

- `images/`：存放所有可视化图表。

- `data/`：清洗后的 Parquet 数据，可直接加载使用。



## 5. 数据局限

本数据集为定向采样（优先抽取核心活跃期的高活用户），因此转化率、复购率均显著高于大盘，分析结论仅适用于高活用户群体，不代表全量用户表现。
