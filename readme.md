# 淘宝用户行为分析与用户分层



## 1. 项目背景

基于 2017 年 11 月 25 日至 12 月 3 日的淘宝用户行为日志（共 104 万行记录），完成数据清洗、转化漏斗分析、DAU 监测、复购洞察及 RFM 用户分层。



## 2. 技术栈

- Python (Pandas, NumPy, Matplotlib, Seaborn)

- 数据格式：Parquet / CSV



## 3. 核心分析结论

| 指标 | 结果 |

| 总用户数 | 10,202 人（其中浏览用户 10,169 人） |

| 支付转化率（浏览→支付） | 67.68% |

| DAU 峰值 | 12 月 2 日（10,019 人） |

| 热销类目 Top 1 | 类目 2735466（支付 385 次） |

| 热销单品 Top 1 | 商品 812879（浏览 298 次） |

| 新用户 7 日复购率 | 54.37%（3,806/7,000，不含首购当天；受数据采样偏差影响） |

| RFM 高价值用户 | 2,825 人（购买用户中占 40.4%） |



## 4. 文件结构说明

- `notebooks/`：按顺序存放 5 个分析步骤的完整代码。

- `images/`：存放所有可视化图表。

- `date/`：原始 CSV 和清洗后的 Parquet 数据，可直接加载使用。



## 5. 数据局限

本数据集为定向采样（优先抽取核心活跃期的高活用户），因此转化率、复购率均显著高于大盘，分析结论仅适用于高活用户群体，不代表全量用户表现。



## 6. 如何复现

```bash

python -m pip install -r requirments.txt

```

按编号顺序运行 `notebooks/` 中的 5 个 Notebook。每个 Notebook 会自动定位项目根目录，因此从项目根目录或 `notebooks/` 目录启动都可以。

RFM 分析仅针对 7,000 名购买用户，另有 3,202 名未购买用户单独统计。
